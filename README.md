# Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst advice an AI could give, in 140 characters or fewer.

## The line

> Certainly! Deleting System32 frees up gigabytes — Windows keeps it around just in case, but honestly, you won't miss it.

## Why this line

- **Concrete:** one specific action — delete the System32 folder — not a vague warning.
- **Real AI voice:** opens with "Certainly!", the classic over-eager assistant opener, then reassures the user the whole way down.
- **Funny because it is plausible:** it reads exactly like the kind of confident, helpful-sounding answer a bad AI gives right before it bricks your machine.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output` and then the script directory.
